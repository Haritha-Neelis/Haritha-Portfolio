# Portfolio Template

This is a simple, editable portfolio website template for showcasing:

- personal experience
- projects
- learning journey
- social/profile links such as LinkedIn, GitHub, LeetCode, and Medium

## Files

- `index.html` — page structure
- `styles.css` — styling and responsive design
- `script.js` — editable profile and content data

## How to customize

1. Open `script.js`.
2. Replace the sample values with your information:
   - `profile.name`
   - `profile.role`
   - `profile.email`
   - `profile.location`
   - `socialLinks`
   - `experienceData`
   - `projectData`
   - `learningData`
3. Update the text in `index.html` such as:
   - hero title
   - about section copy
   - contact section
   - page title

## How to run locally

You can open `index.html` directly in a browser, or run a local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes

This template is designed to be easy to extend. You can add new cards or sections by copying the pattern already used in `script.js` and the HTML containers.
